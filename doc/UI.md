# 結果表示UI

## Summary

### ヘッダー

結果表示画面のヘッダーには、現在の出発地点名を含めて表示する。

```text
バス候補（{出発地点名}）
```

ヘッダーは今後、スクロールしても画面上部に固定表示する想定とする。  
そのため、本文側では出発地点名を再表示しない。

### 目的地候補別の最短到着

Recommended の下には、目的地候補別の最短到着を比較するサマリー表を表示する。

この表は、各目的地候補に対して最短で到着できる候補を1つずつ表示する。  
目的地候補は横方向、比較項目は縦方向に配置する。

```text
目的地候補別の最短到着

[目的地]      [岐阜大学病院] [柳戸橋] [岐阜大学]
[バス停着]    {hh:mm}      {hh:mm}  {hh:mm}
[発車]        {hh:mm}      {hh:mm}  {hh:mm}
[降車]        {hh:mm}      {hh:mm}  {hh:mm}
[徒歩]        {mm}分       {mm}分   {mm}分
```

### 乗車可能な便がない場合

現在時刻以降に乗車可能な便が存在しない場合でも、Summary は必ず表示する。  
この場合も、出発地点から各目的地候補の乗車バス停までの徒歩時間と、バス停到着予定時刻は有効な情報として扱う。

見出し「目的地候補別の最短到着」の直下に、次のメッセージを表示する。

```text
現在時刻以降に乗車可能な便がありません
```

表示形式は次の通りとする。

```text
目的地候補別の最短到着

現在時刻以降に乗車可能な便がありません

[目的地]      [岐阜大学病院] [柳戸橋] [岐阜大学]
[バス停着]    {hh:mm}      {hh:mm}  {hh:mm}
[発車]        --:--        --:--    --:--
[降車]        --:--        --:--    --:--
[徒歩]        {mm}分       {mm}分   {mm}分
```

このケースでの各項目は次のように扱う。

| 表示名   | 扱い                                                                 |
| -------- | -------------------------------------------------------------------- |
| バス停着 | 現在時刻を基準に、出発地点から各乗車バス停へ移動した場合の到着予定時刻 |
| 発車     | 現在時刻以降に乗車可能な便がないため、すべて `--:--`                  |
| 降車     | 乗車できる便がないため、すべて `--:--`                                |
| 徒歩     | 出発地点から各乗車バス停までの徒歩時間                                |

例:

```text
現在時刻: 12:00
岐阜大学病院まで徒歩5分
柳戸橋まで徒歩3分
岐阜大学まで徒歩4分

[バス停着]    12:05        12:03    12:04
```

このケースの `--:--` は、現在時刻以降に乗車可能な便がなく、発車時刻または降車時刻を表示できないことを意味する。

徒歩時間が計算できる場合は必ず表示する。  
徒歩時間が計算できない場合のみ、該当セルは既存のフォールバック表示に合わせる。

Summary 用のデータは、バス候補が0件の場合でも生成する。  
発車時刻と降車時刻は null のまま画面へ出さず、表示時に `--:--` へフォールバックする。

Recommended と Candidates は、乗車可能な候補が1件以上ある場合にだけ表示する。  
乗車可能な便がない場合、次のような空カードや代替カードは表示しない。

| 領域        | 表示しないもの                                      |
| ----------- | --------------------------------------------------- |
| Recommended | おすすめ候補なし、Option なし、空カード、`--:--` だけのカード |
| Candidates  | 候補一覧なし、空カード、`--:--` だけのカード、Option 表記だけのカード |

### 表示項目の意味

| 表示名   | 意味                                               |
| -------- | -------------------------------------------------- |
| 目的地   | 降車する目的地候補のバス停                         |
| バス停着 | 出発地点から移動して、乗車バス停に到着する予定時刻 |
| 発車     | 乗車バス停からバスが発車する時刻                   |
| 降車     | 目的地候補のバス停に到着し、バスを降りる時刻       |
| 徒歩     | 出発地点から乗車バス停までの移動時間               |

### サマリーに表示しない項目

以下の項目は、サマリー表には表示しない。

| 項目     | 扱い                               |
| -------- | ---------------------------------- |
| 待ち時間 | 詳細表示または候補一覧側で表示する |
| 車内時間 | 詳細表示または候補一覧側で表示する |
| 合計時間 | 詳細表示または候補一覧側で表示する |
| バスID   | 詳細表示または候補一覧側で表示する |

### 用語定義

| 用語     | 定義                                               |
| -------- | -------------------------------------------------- |
| 徒歩時間 | 出発地点から乗車バス停までの移動時間               |
| 待ち時間 | 乗車バス停に到着してから、バスが発車するまでの時間 |
| 車内時間 | バスに乗ってから、降車バス停で降りるまでの時間     |
| 合計時間 | 徒歩時間 + 待ち時間 + 車内時間                     |

### 設計判断

サマリーは、目的地候補ごとの最短到着を素早く比較するための領域とする。  
そのため、サマリーでは次の情報だけを表示する。

```text
バス停着
発車
降車
徒歩
```

待ち時間、車内時間、合計時間、バスIDは比較表に入れると情報量が増えすぎるため、サマリーには表示しない。  
これらは候補一覧または詳細展開で確認できるようにする。

## Recommended

### おすすめ候補

結果本文の先頭に、最も推奨する候補を1件表示する。

おすすめ候補は、ユーザーが次に取る行動を最小限の情報で示す領域とする。  
比較や詳細確認ではなく、「どのバス停へ向かい、何時発のバスに乗ればよいか」を即座に判断できる表示にする。

```text
おすすめ候補

{乗車バス停名}
発車：{発車時刻}（到着予定：{降車予定時刻}）
徒歩：{mm}分 余裕：{mm}分

Option {optionNumber}
```

### 表示項目の意味

| 表示名       | 意味                                               |
| ------------ | -------------------------------------------------- |
| 乗車バス停名 | ユーザーが向かうべき乗車バス停                     |
| 発車         | 乗車バス停からバスが発車する時刻                   |
| 到着予定     | 目的地候補のバス停に到着する予定時刻               |
| 徒歩         | 出発地点から乗車バス停までの移動時間               |
| 余裕         | 乗車バス停に到着してから、バスが発車するまでの時間 |
| Option       | 候補一覧側の同一候補と対応させるための識別番号     |

### 表示しない項目

以下の項目は、おすすめ候補には表示しない。

| 項目         | 扱い                                           |
| ------------ | ---------------------------------------------- |
| 降車バス停名 | Summary または候補一覧側で確認する             |
| 車内時間     | 詳細情報として扱い、おすすめ候補には表示しない |
| 合計時間     | 比較情報として扱い、おすすめ候補には表示しない |
| バスID       | 候補一覧側で表示する                           |
| 詳細を見る   | おすすめ候補には表示しない                     |

### 設計判断

おすすめ候補は、詳細な比較ではなく、ユーザーがすぐに行動できることを優先する。  
そのため、表示項目は乗車バス停名、発車時刻、到着予定時刻、徒歩時間、余裕時間、Option 表記に限定する。

Option はおすすめ候補カードの一番下に表示する。  
Recommended に表示する Option は、Candidates 側の同一候補の Option 番号と一致させる。

余裕は、内部的には待ち時間と同じ値を指す。  
ただし UI 表示では、ユーザーが「間に合う余白」として判断しやすいように `余裕` と表記する。

## Candidates

### 候補一覧

Summary の下に、利用可能なバス候補を一覧表示する。

候補一覧は、目的地候補ごとではなく、バスごとに表示する。  
各バスが、それぞれの目的地候補に対して利用可能かどうかを比較できるようにする。

各候補はカード単位で表示する。  
カード上部にバスIDまたは路線名を表示し、その下に目的地候補別の時刻表を表示する。  
Option 表記は各カードの一番下に表示する。

```text
候補一覧

{バスIDまたは路線名}

[目的地]      [岐阜大学病院] [柳戸橋] [岐阜大学]
[バス停着]    {hh:mm}      {hh:mm}  {hh:mm}
[発車]        {hh:mm}      {hh:mm}  {hh:mm}
[降車]        {hh:mm}      {hh:mm}  {hh:mm}

Option {optionNumber}
```

### 表示項目の意味

| 表示名             | 意味                                                   |
| ------------------ | ------------------------------------------------------ |
| バスIDまたは路線名 | 候補を識別するための名称                               |
| 目的地             | 降車する目的地候補のバス停                             |
| バス停着           | 出発地点から移動して、乗車バス停に到着する予定時刻     |
| 発車               | 乗車バス停からバスが発車する時刻                       |
| 降車               | 目的地候補のバス停に到着し、バスを降りる時刻           |
| Option             | Recommended 側の同一候補と対応させるための識別番号     |
| --:--              | そのバスでは該当目的地候補に利用できないことを示す表示 |

### `--:--` の扱い

以下のいずれかに該当する場合、該当する時刻欄には `--:--` を表示する。

| 条件                       | 意味                                                                 |
| -------------------------- | -------------------------------------------------------------------- |
| 該当目的地候補に停車しない | そのバスでは目的地候補まで移動できない                               |
| 発車に間に合わない         | 出発地点から乗車バス停へ移動しても、そのバスの発車時刻に間に合わない |
| 到着予定時刻を計算できない | 必要な時刻情報または経路情報が不足している                           |

### Option 表記

Recommended と Candidates の両方で、各候補に Option 表記を付与する。

Option は表示順に `Option 1`, `Option 2`, `Option 3` のように採番する。  
Recommended に表示する Option は、Candidates 側の同一候補の Option 番号と一致させる。

Candidates では、Option 表記を各候補カードの一番下に表示する。

### 設計判断

候補一覧は、ユーザーが各バス候補を比較するための領域とする。  
そのため、Summary のように目的地候補ごとの最短候補だけを表示するのではなく、バスごとに目的地候補別の時刻を表示する。

候補一覧では、バスIDまたは路線名を表示する。  
これは、複数の候補を区別するために必要な情報であり、Recommended では省略しても Candidates では表示する。

徒歩時間、待ち時間、車内時間、合計時間は候補一覧には表示しない。  
候補一覧では、バス停着、発車、降車の時刻を優先して表示する。
