# Home UI 修正仕様

## 対象

トップ画面の以下の要素を修正対象とする。

- マップ
- 出発地点プルダウン
- GPS による現在地取得
- 最寄り出発地点選択ボタン
- ヘッダー
- 設定ボタン
- 雨天モード

## 目的

- ユーザーが「現在地」「選択中の出発地点」「選択可能な出発地点」「バス停」をマップ上で明確に区別できるようにする。
- GPS 現在地と経路探索に使う出発地点を混同しない UI にする。
- 出発地点プルダウンと GPS 由来の最寄り選択を連動させ、ユーザーが検索前に出発地点を確認できるようにする。
- 設定ボタンをヘッダーに統合し、トップ画面の構造を整理する。
- 既存の雨天モードは維持する。

## 状態管理

GPS 現在地と検索に使う出発地点は別の状態として管理する。

- GPS 現在地: デバイス GPS から取得した緯度経度
- 出発地点: 経路探索に使う `CampusGraphNode`

想定する状態は以下とする。

- `currentLocation: LatLng?`
- `selectedStartNode: CampusGraphNode`

GPS 現在地を取得しただけでは `selectedStartNode` を自動変更しない。
`selectedStartNode` を変更するのは、以下の場合のみとする。

- ユーザーが出発地点プルダウンを変更した場合
- ユーザーが「現在地から選択」ボタンを押し、GPS 現在地から最寄りの選択可能ノードを選択した場合

## ヘッダー

トップ画面上部にヘッダーを追加する。

- ヘッダー左側に「岐大バスナビ」と表示する。
- ヘッダー右側に設定ボタンを配置する。
- 現在トップ画面内にある既存の設定ボタンは削除し、ヘッダー内の設定ボタンに統合する。
- 設定ボタンの遷移先や機能は既存の設定ボタンと同じにする。

## 出発地点選択エリア

出発地点プルダウンと「現在地から選択」ボタンを同じ行に横並びで配置する。

```text
[ 出発地点プルダウン ][ 現在地から選択 ]
```

### レイアウト

- 左側に出発地点プルダウンを配置する。
- 右側に「現在地から選択」ボタンを配置する。
- プルダウンは可能な限り横幅を広く取る。
- ボタンは内容に必要な最小幅を基本とする。
- 画面幅が狭い場合も崩れないようにする。

### 出発地点プルダウン

- 出発地点プルダウンには、選択可能な `CampusGraphNode` のみを表示する。
- デフォルトでは、よく使う出発地点を初期選択にする。
- よく使う出発地点の定義が既にある場合はそれを利用する。
- 定義がない場合は、固定の `frequentStartNodes` リストを用意し、その先頭を初期選択にする。
- `frequentStartNodes` が空、または無効な場合は、選択可能な `CampusGraphNode` 一覧の先頭を初期選択にする。
- プルダウンで選択を変更した場合、`selectedStartNode` を更新し、マップ上の選択中表示も更新する。

## 「現在地から選択」ボタン

出発地点プルダウンの右側に「現在地から選択」ボタンを追加する。

### 動作

- 「現在地から選択」ボタンを押したら、デバイス GPS から現在地を取得する。
- 取得した現在地の緯度経度から、選択可能な `CampusGraphNode` のうち最も距離が近いノードを計算する。
- 最寄りノードを `selectedStartNode` に設定する。
- 出発地点プルダウンの表示値も、その最寄りノードに更新する。
- マップ上でも、そのノードを選択中表示に更新する。
- ユーザーはマップ上で選択された最寄りノードの位置を確認できる。
- その出発地点でよければ、ユーザーが「最短バスを探す」ボタンを押して検索する。

### GPS 取得失敗時

- GPS 現在地を取得できなかった場合は、プルダウンの値を変更しない。
- ユーザーに現在地を取得できなかったことを表示する。
- 必要に応じて、位置情報権限や GPS 設定の確認を促す。

## 「最短バスを探す」ボタン

- 「最短バスを探す」は、常に `selectedStartNode` を出発地点として扱う。
- GPS 現在地そのものを直接出発地点として扱わない。
- GPS を使いたい場合は、ユーザーが「現在地から選択」ボタンを押して `selectedStartNode` を更新する流れにする。

## マップ上の地点表示

マップ上に以下の地点を表示する。

- GPS 現在地
- バス停
- プルダウンで選択されている出発地点
- 選択可能な出発地点候補

## ピンの描画仕様

ピンは、外側の円の上に内側の円を重ねる方式で描画する。

外側円と内側円の半径比は、全種類のピンで統一して `3:2` とする。

つまり、外側円の半径を `3` とした場合、内側円の半径は `2` とする。

このとき、外枠部分の太さは以下になる。

```text
外枠部分の太さ = 外側円の半径 - 内側円の半径
              = 3 - 2
              = 1
```

したがって、外枠部分と内側円の半径比は `1:2` になる。

実装上は、実際の表示サイズに合わせて同じ比率でスケーリングする。

例:

```text
外側円の半径: 9dp
内側円の半径: 6dp
外枠部分の太さ: 3dp

外側円の半径: 12dp
内側円の半径: 8dp
外枠部分の太さ: 4dp
```

どのサイズを採用する場合でも、外側円半径 : 内側円半径 = `3:2` を維持する。

## ピンの配色

### 現在地

GPS 現在地は以下の配色で表示する。

- 外側円: 黒
- 内側円: 緑

### バス停

バス停は以下の配色で表示する。

- 外側円: 赤
- 内側円: 白

例として、半径 `3` の赤色の円の上に、半径 `2` の白色の円を重ねたものを、実際の UI サイズに合わせて拡大または縮小して表示する。

### プルダウンで選択されている出発地点

選択中の出発地点は以下の配色で表示する。

- 外側円: 黒
- 内側円: 黄

### 選択可能な出発地点候補

選択可能な出発地点候補は以下の配色で表示する。

- 外側円: 黒
- 内側円: 白

## ピンの表示優先順位

同じ地点が複数の属性を持つ場合は、以下の優先順位で表示する。

1. GPS 現在地
2. プルダウンで選択中の出発地点
3. バス停
4. 選択可能な出発地点候補

ただし、バス停がプルダウンで選択中の出発地点でもある場合は、選択中表示を優先し、以下の配色で表示する。

- 外側円: 黒
- 内側円: 黄

## 雨天モード

- 既存の雨天モードの状態、表示、ロジックは維持する。
- 今回の修正で雨天モードの挙動が変わらないようにする。

## 実装上の注意

- GPS 現在地と `selectedStartNode` は別の状態として管理する。
- GPS 取得だけでは `selectedStartNode` を自動変更しない。
- `selectedStartNode` が変更された場合は、プルダウン表示、マップ上の選択中表示、「最短バスを探す」の出発地点がすべて同じ値を参照するようにする。
- マップ上の点が重なって文字や円が見づらくならないように、既存のラベル表示や描画順も確認する。
- 既存機能を壊さないように、トップ画面、マップ表示、出発地点選択、GPS 取得、雨天モード、設定画面遷移を確認する。
